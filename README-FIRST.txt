PROJECT MIDNIGHT GOLD 2.0
========================

START HERE
1. Extract the ZIP.
2. Open the PROJECT-MIDNIGHT-GOLD-2.0 folder.
3. Open index.html in a browser (Chrome recommended).
4. Keep the folder structure intact. Do not move HTML files away from css/, js/, images/, audio/, or assets/.

PAGE ORDER
index.html (Login)
  -> question.html
  -> loading.html
  -> main.html (Hero)
  -> moments.html
  -> memory-vault.html
  -> birthday-quiz.html
  -> starry-wishes.html
  -> cake.html
  -> fireworks.html
  -> final.html

PROJECT NOTES
- All 11 pages created/assembled so far are included.
- The 10 uploaded Memory Vault photos are included under assets/memory-vault/.
- Keep the existing css/ and js/ folders beside the HTML files.
- GSAP and ScrollToPlugin are loaded from their existing CDN references; an internet connection is needed for those external libraries and web fonts.
- The original Cake, Fireworks and Final CSS/JS files are carried over unchanged. Their HTML files use the local 2.0 shared stylesheet/transition wiring so navigation works in this combined project.
